# AIVT Log

AIVTの非公開ログ。公開リポジトリに出す前の考え、作戦、実験メモ、AIモデル観察、応募準備、運用記録を置く場所。

公開リポジトリ `AIVT` は外向けのプロジェクト本体。  
このリポジトリは、見せる前の考え・本音・比較・未整理メモを置く軍議室。

## ファイル構成

- `devlog.md` — 開発ログ、発端、ユースケース、実装方針
- `strategy.md` — AIVTの育成方針、応募・公開・宣伝の作戦
- `model-usage-log.md` — Claude Code / Codex / GPT Business などの使用感と制限記録
- `promotion.md` — 宣伝、反応、フィードバック、ユーザー需要の記録
- `application-draft.md` — 将来の応募文面・申請材料の下書き

## 運用方針

- 公開してよい内容は `AIVT` 側へ清書する。
- 本音、応募戦略、未整理メモ、反応分析はこの `AIVT-log` に置く。
- あとで応募やREADMEに使えそうな内容は、ここで育ててから外向けに整える。
- AIモデルそのものの比較だけでなく、AIVTを作る過程で見えたClaude Code / Codex / GPT Businessの違いも記録する。
